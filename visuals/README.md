# Visuals

This folder contains the main visualizations created for the German BookTok bestseller analysis.

## Visualizations

- **Genre Volume vs. Chart Persistence**  
  Compares the number of unique titles per genre with their average chart duration.

- **Top 10 Publishers**  
  Shows the publishers with the highest number of unique titles appearing in the German BookTok Top 20.

- **Publisher Presence by Genre**  
  Heatmap showing which publishers are most represented across the main BookTok genre categories.

- **Backlist Chart Persistence**  
  Compares the average chart duration of new releases with older titles.

The interactive versions of these visualizations were created in Tableau.
